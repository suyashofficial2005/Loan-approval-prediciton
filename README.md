Loan Approval Prediction System
This project predicts whether a loan will be approved using Machine Learning.

Features
User-friendly Streamlit web app
Predicts loan approval instantly
Uses trained ML model

Tech Stack
Python
Streamlit
Scikit-learn
Pandas, NumPy

How to Run
Install dependencies: pip install -r requirements.txt
Run the app: streamlit run app3.py

Dataset
Loan Dataset used for training the model
